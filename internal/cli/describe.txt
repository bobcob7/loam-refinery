A review document is one JSON object. Unknown fields are rejected.

root
  version     "1"
  verdict     approve | request_changes | comment
  summary     1-3 sentences, 30-1500 chars
  ref         40-char lowercase commit SHA; required, read by every anchor
  profile     kebab-case name; optional, for collect-reviews attribution
  comments    array; empty only when verdict is approve
  assessment  strong | sound | mixed | weak; optional, ordinal quality grade orthogonal to verdict

comment
  id           kebab slug + number, e.g. missing-context-2; unique
  priority     1-10: 9-10 blocks, 7-8 should fix, 4-6 worth fixing, 1-3 optional
  category     correctness | security | performance | maintainability | testing
               | documentation | style
  body         the finding and its rationale, 20-4000 chars
  code         optional excerpt of the problem; soft
  anchors      array of { file, line?, end_line? }; may be empty
  suggestions  array; may be empty

suggestion
  summary  what to do, one sentence, 10-500 chars
  effort   trivial | small | medium | large        — how much work
  scope    line | block | file | module | project  — blast radius
  pros     array of strings
  cons     array of strings
  code     optional excerpt of the fix; soft
